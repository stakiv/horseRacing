# Курсовая работа "Ипподром"

## Описание
Это веб-приложение для отображения заездов, лошедей и жокеев. В нем реализована возможность фильтровать по названию ипподрома, дате, лошади и жокею  заезды; сортировать по количеству побед и по алфавиту лошадей и жокеев, а также добавлять новых и удалять. 

### Основные возможности:
- Отображение списка заездов с участниками (лошадь, жокей, время)
- Фильтрация заездов по: названию ипподрома, по дате провеления заезда, по кличке лошади, по имени жокея
- Отображение списка лошадей (Id, кличка, масть, возраст, имя владельца, количество побед)
- Сортировка лошадей по алфавиту и по количеству побед
- Возможность добавления/удаления лошадей
- Отображение списка жокеев (Id, имя, возраст, количество побед)
- Сортировка жокеев по алфавиту и по количеству побед
- Возможность добавления/удаления жокеев

## Технологии и инструменты:
- **React** - основной фреймворк для разработки фронтенда веб-приложения
- **Express** - для создания RESTful API и бэкенд сервера на Node.js
- **PostgreSQL** - база данных для хранения и управления данными
- **pg (node-postgres)** - библиотека для взаимодействия PostgreSQL и Node.js
- **dotenv** - для управления конфиденциальными перемнными окружения
- **CSS Modules**


## Структура проекта

## Фронтенд

### 1. forms
  - **add_form.jsx** — компонент формы для добавления новых записей в систему. В зависимости от переданного пропса nameType отображает форму для добавления либо новой лошади, либо нового жокея.

    Загружает необходимые данные (владельцев, лошадей, масти) с сервера через API, отправляет POST-запросы на сервер для добавления новых лошадей или жокеев, поддерживает валидацию обязательных полей.
    
  - **delete_form.jsx** — компонент формы для удаления записей из системы. В зависимости от переданного пропса nameType отображает форму для удаления либо лошади, либо жокея.

    Загружает список владельцев и жокеев с сервера, а также лошадей, принадлежащих выбранному владельцу, отправляет DELETE-запросы на сервер для удаления выбранной лошади или жокея.

  - **add_from.module.css, delete_form.module.css** - модули стилизации для форм

### 2. horses
  - **horses.jsx** - основной компонент страницы для управления списком лошадей

    Загружает данные о лошадях с сервера и отображает их в табличном формате, позволяет сортировать список лошадей по количеству побед или в алфавитном порядке, обновляя данные с сервера.

  - **horses.module.css** - модуль стилизации страницы списка лошадей

### 3. jockeys
  - **jockeys.jsx** - основной компонент страницы для управления списком жокеев

    Загружает данные о жокеях с сервера и отображает их в табличном формате, позволяет сортировать список жокеев по количеству побед или в алфавитном порядке, обновляя данные с сервера.

  - **jockeys.module.css** - модуль стилизации страницы списка жокеев

### 4. main_el
  - **tabs.jsx** - компонент вкладок для переключения между основными разделами приложения: Заезды, Лошади и Жокеи.

    Использует хук useState для управления активной вкладкой, отображает навигационные кнопки (вкладки) с визуальным выделением текущей активной, в зависимости от выбранной вкладки рендерит соответствующий компонент: Races, Horses или Jockeys.

  - **tabs.module.css** - модуль стилизации компонента вкладок

### 5. races
  - **races.jsx** - основной компонент страницы с заездами.

    Позволяет фильтровать заезды по ипподрому, дате, лошади и жокею с помощью выпадающих списков и поля даты, загружает данные по заездам, ипподромам, лошадям и жокеям с сервера через API, отслеживает изменения фильтров и обновляет список заездов автоматически.

  - **race_item.jsx** - компонент для отображения подробной информации о конкретном заезде.

    Принимает в пропсах ID заезда, название и дату, загружает список участников заезда (лошадей, жокеев и время) с сервера по ID заезда, отображает данные в табличном виде с номерами, именами лошадей, жокеев и временем заезда.

  - **races.module.css, race_item.module.css** - модули стилизации страницы заездов и компонентов заездов



## Бэкенд

### 1. controllers
  В этой папке находятся контроллеры, реализующие логику обработки HTTP-запросов к серверу Express и взаимодействия с базой данных PostgreSQL.

  Основные функции контроллеров:
  - Обработка запросов CRUD (создание, чтение, обновление, удаление) для основных сущностей приложения: лошади, жокеи, заезды, ипподромы, владельцы и др.

  - Выполнение SQL-запросов через клиент pg для получения, добавления или удаления данных в базе PostgreSQL.

  - Валидация и обработка ошибок, возвращение корректных HTTP-статусов и сообщений клиенту.

  - Разграничение логики: каждый контроллер отвечает за свой набор маршрутов и операций (например, добавление лошади, удаление жокея, получение списка заездов).

### 2. routers
  Папка routers содержит модули маршрутизации, которые определяют эндпоинты API и связывают их с соответствующими контроллерами.
  
  Основные функции папки:
  - Определение маршрутов для различных ресурсов и операций (например, добавление лошади, удаление жокея, получение списка владельцев и т.д.)
    
  - Подключение контроллеров к маршрутам, чтобы изолировать логику обработки запросов от определения маршрутов.
    
  - Использование express.Router() для создания отдельных роутеров, которые затем подключаются в основном серверном приложении.

### 3. index.js
  Главный файл запуска и настройки сервера Express
  
  Основные функции файла:
  - Инициализация Express-приложения и подключение встроенного middleware для парсинга JSON в теле запросов (express.json()).

  - Настройка CORS — добавление заголовков, разрешающих кросс-доменные запросы с любых источников ('*'), а также поддержку основных HTTP-методов и заголовков.

  - Подключение роутеров из папки routers к базовому пути /api

  - Запуск сервера на порту 1337 с выводом сообщения о готовности к работе.

  - Обработка сигнала завершения приложения (SIGINT), чтобы корректно завершить работу сервера и вывести сообщение об остановке.
